# Проверка предварительного Windows-приложения Publisher 0.2.0

Результат: `output/desktop/Publisher-Setup-0.2.0-windows-x64.exe`, 52 076 965 байт. SHA-256 находится рядом с установщиком. Это предварительный неподписанный выпуск.

## Реализовано

- Самостоятельный Windows x64 пакет с Python, frontend, зависимостями, значком и уведомлениями о лицензиях.
- Установщик под текущим пользователем, ярлыки, опциональный автозапуск, сохранение пользовательских данных при удалении.
- Защищённый локальный мастер: новая установка, прежний неуправляемый бот, проверенная резервная копия. Новая очередь остаётся на паузе; восстановленная очередь требует повторной проверки.
- Повторный запуск открывает существующий host. Фоновый запуск не создаёт второй runtime. Значок в трее и корректная остановка.
- Подключение Telegram с проверкой токена и управляемым перезапуском runtime.
- Несколько зашифрованных AI-подключений: LM Studio, Ollama, совместимые локальные/сетевые/облачные Chat Completions + JSON Schema API. Раздельный выбор для новостей и перевода названий, явное согласие на облачную обработку.
- Host-owned AI workers используют существующие аренды и авторизацию, без отдельной команды привязки. Повтор запроса добавления не создаёт второго worker.
- Локальная проверенная копия перед повторной установкой/обновлением; сохранён штатный переносимый backup/restore с паролем.
- Отчёт диагностики без секретов и пользовательских текстов; краткая инструкция для пользователя.
- Проверяемый исходный release ZIP входит в пакет и регистрируется host для существующего механизма размещения.

## Выполненные проверки

1. Полный набор: **610 passed, 1 skipped**. Пропущен opt-in тест собранного EXE, который затем выполнен отдельно. Проверки legacy выполнялись вне OneDrive в разрешённой временной папке.
2. После обработки ограниченного доступа к реестру: **14 desktop-тестов пройдены**.
3. Проверка реального EXE: **1 passed**. Отдельные host/runtime, вход, защищённые desktop endpoints, выдача frontend, запрос к локальному макету совместимого AI, сохранение зашифрованного подключения, перевод названия через очередь и worker, повторный запуск, диагностика и корректная остановка. Системный Python для дочернего runtime не используется.
4. Проверка установщика с тем же payload и отключённой регистрацией тестового выпуска в реестре: **1 passed**. Установка в изолированную папку, повторная установка, проверенная локальная копия, удаление программы с сохранением данных. Создание настоящих ярлыков и регистрация в списке программ в ограниченной среде не подтверждены.
5. Frontend: сборка и TypeScript проверены, **7 client-тестов пройдены**.
6. Визуально просмотрены мастер первого запуска и страница «Приложение» из собранного EXE на изолированных материалах.

Первые запуски EXE обнаружили пропущенные динамические зависимости unittest/aiosqlite; они добавлены. Ограничение доступа к реестру больше не нарушает загрузку страницы состояния.

## Что остаётся для публичного выпуска

- Сертификат издателя и подпись приложения/установщика.
- Публичная страница скачивания, правила лицензирования самого проекта, описание обработки данных и канал поддержки.
- Доверенный канал автоматической доставки обновлений. Сейчас обновление выполняется повторным запуском установщика; автоматический откат несовместимой схемы не реализован.
- Проверка чистой Windows без инструментов разработчика, реального автозапуска и системных ярлыков, испытания с новыми пользователями.
- Испытания на конкретных AI-сервисах, тестовом Telegram-канале и реальных серверах/доменах для SSH/HTTPS/Mini App. В этом проходе внешние публикации и платные AI-запросы не выполнялись.

Локальные тесты не заменяют перечисленные внешние проверки и не означают готовность публичного размещения.
