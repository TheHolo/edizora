# Edizora для Windows

[Скачать Edizora 0.1](https://github.com/TheHolo/edizora/releases/download/v0.1/edizora.exe) · [Все выпуски](https://github.com/TheHolo/edizora/releases)

1. Откройте `edizora.exe` и завершите установку. Python, Node.js и терминал не нужны.
2. Запустите Edizora через ярлык. Выберите новую установку, перенос прежнего бота или восстановление проверенной копии.
3. Укажите свой числовой Telegram ID и придумайте пароль панели не короче 12 символов. Для переноса и восстановления укажите действующего администратора из прежней установки.
4. В панели «Приложение» подключите токен бота, созданного у @BotFather. Затем добавьте бота администратором канала и проверьте права в разделе «Каналы».
5. При необходимости подключите AI. Выберите LM Studio, Ollama или совместимый с OpenAI API сервис, задайте адрес и точное имя модели. Ключ нужен только тогда, когда его требует сервис. Нажмите «Проверить ответ модели», затем «Сохранить и использовать».
6. Создайте первый черновик и проверьте предпросмотр. Перед отправкой снимите общую паузу в очереди.

## Что выбрать для AI

LM Studio на этом компьютере: запустите локальный сервер в программе, загрузите текстовую модель и укажите её имя. Пример адреса: `http://127.0.0.1:1234/v1`.

Ollama на этом компьютере: укажите установленную модель и адрес `http://127.0.0.1:11434`.

Другой локальный или облачный сервис: выберите совместимый с OpenAI API протокол и полный базовый адрес, который сообщает провайдер, обычно с `/v1`. Поддерживаются Chat Completions и структурированные ответы JSON Schema. Проверка выполняет небольшой запрос; она не гарантирует качество обработки всех новостей.

Облачный сервис получает тексты задач и может взимать плату, включая тестовый запрос. Перед подключением подтвердите передачу текстов. Автоматического перехода на другой облачный сервис нет. В сохранённых подключениях можно отдельно выбрать модели для новостей и перевода названий.

## Ежедневная работа

Ярлык открывает панель уже работающего приложения. Закрытие вкладки оставляет Edizora в фоне. Значок рядом с часами позволяет открыть панель, папку журналов или корректно остановить приложение. Автозапуск включается при установке либо на странице «Приложение».

Для публикаций по расписанию компьютер должен оставаться включённым и не спать. Локальная панель доступна только на этом компьютере. Для доступа из Telegram Mini App требуется отдельное размещение с HTTPS.

## Данные, обновление и помощь

Программа устанавливается в `%LOCALAPPDATA%\Programs\Edizora`, данные и настройки хранятся отдельно в `%LOCALAPPDATA%\Edizora`. Удаление программы сохраняет данные. Не переносите рабочую базу в OneDrive.

Для обновления остановите Edizora через его меню и запустите установщик новой версии. Перед заменой программа создаёт проверенную локальную копию в `update-backups`. Это копия для прежнего Windows-аккаунта; для переноса на другую машину используйте резервное копирование с паролем восстановления в панели.

В разделе «Резервные копии» доступны ручные копии, расписание и восстановление. Для первого запуска на новой машине можно выбрать восстановление в мастере и указать папку проверенной копии. Прежние экземпляры должны быть остановлены; восстановленная очередь переводится в черновики для проверки повторных публикаций. Веса локальных моделей и локальные ключи AI потребуется подключить заново.

На странице «Приложение» можно скачать отчёт для поддержки. Он содержит версии и состояние компонентов без токенов, паролей и текстов публикаций.

Это предварительный выпуск. Установщик пока не подписан сертификатом издателя, автоматическая доставка обновлений не включена. До публичного выпуска нужны подпись, проверка на чистой Windows и испытания с новыми пользователями.
