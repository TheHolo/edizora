# Состояние проекта

Проверено 10 сентября 2026 года по текущим файлам, тестам, локальному LM Studio и Telegram API.

**Реализованы редактор альбомов, английский перевод названий и выбор модели LM Studio. Каналы обновлены в рабочей SQLite и `.env`. Для использования обновлённого кода запустите `start-local.cmd`.**

## Что работает в коде

| Компонент | Реализовано |
| --- | --- |
| Редактор альбома | миниатюры по 9 на страницу, включение/исключение кадров, перемещение, первый кадр, ручной порядок, предпросмотр |
| Сохранение альбома | каталог, выбранные номера и порядок хранятся в SQLite; защита от устаревших правок, пустой альбом нельзя отправить в очередь |
| Перевод названий | английский через LM Studio, MyMemory при ошибке или таймауте; перевод сохраняется в черновике |
| Выбор модели | `/models` показывает текстовые модели, состояние загрузки и кнопки выбора; есть обновление списка и страницы |
| Применение выбора | общий выбор для новых переводов и локальных новостей; начатые новости сохраняют модель до завершения; ожидающие и повторные получают текущую модель |
| Сохранение выбора | `<storage_path>/lmstudio-model.json`, привязка к адресу LM Studio, приоритет над начальным ID в `.env`/TOML |
| Каналы и теги | автоматические теги канала видны в карточке, предпросмотре и публикации; меняются при переносе черновика в другой канал |
| Локальный запуск | `.venv-local`, бот и обработчик новостей в одном процессе, диагностика, блокировка повторного запуска и резервная копия SQLite |

Для возврата к черновику: `/recent` → `/preview <id>` → «🗂 Редактор альбома».
Список `7,1,5,3` заменяет выбор и порядок целиком. «Исходный выбор» возвращает состояние при создании черновика.
В ранее сохранённых переводах текст не меняется автоматически при выборе другой модели.

## LM Studio на этой машине

API `http://127.0.0.1:1234` доступен. Каталог содержит четыре текстовые модели:

- `google/gemma-4-12b-qat`
- `qwen/qwen3.8-27b`
- `qwen3.6-35b-a3b-uncensored-hauhaucs-aggressive`
- `qwen3.8-27b-obliterated`

На момент проверки ни одна не загружена в память. Начальная настройка `.env` — `qwen/qwen3.8-27b`; теперь её можно переопределить кнопкой в `/models`. Для автоматической загрузки выбранной модели нужен JIT loading в LM Studio; иначе загрузите её вручную. Embedding-модель исключена из меню.

Перевод названий настроен на английский, резерв MyMemory включён. Новая генерация при этой проверке не запускалась.
Выбор доступной Gemma через реальный каталог и восстановление настройки проверены во временной папке; рабочая начальная модель не изменена.

## Проверки и запуск

**385 тестов прошли**, в том числе сохранение выбора, смена модели между заданиями, сохранение модели для начатого запроса, фильтрация embedding-моделей, устаревшие кнопки, обновление очереди новостей и миграция каналов. `app.local --check` завершилась без ошибок.

```powershell
# Показать модели
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\run-local.ps1 -Models

# Выбрать модель без запуска бота
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\run-local.ps1 -Model "google/gemma-4-12b-qat"

# Проверить установку
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\run-local.ps1 -Check

# Запустить
.\start-local.cmd
```

После запуска: `/models` → выбор модели, `/channels` → проверка каналов. Для ручной проверки редактора: `/new` → ссылка на альбом → выбор кадров → предпросмотр. Нажатие кнопок в настоящем чате Telegram ещё требует проверки пользователем; обработчики проверены автоматическими тестами.

В старых черновиках, созданных до редактора с частичным выбором `[1,3,…]`, сохранены только ранее выбранные изображения; полный каталог появится при новом импорте ссылки. Редактор пока не включает обрезку изображений и историю отмены отдельных действий.
