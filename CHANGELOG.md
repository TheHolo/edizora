# История выпусков Edizora

## 0.1 — 27 октября 2026

Первый выпуск под именем **Edizora (Эдизора)**.

- Английский интерфейс по умолчанию; выбор English / Русский в настройках с сохранением в браузере. Английский мастер первого запуска и двуязычный установщик.
- Имя Edizora в панели, заголовке вкладки, мастере первого запуска, трее и ярлыках Windows.
- Версия 0.1 в интерфейсе и свойствах исполняемого файла.
- Установщик `edizora.exe` для Windows 10/11 x64, включающий Python и веб-интерфейс.
- Подключение Telegram, LM Studio, Ollama и сервисов с совместимым AI API.
- Черновики изображений и новостей, редактор, очередь, расписание и несколько каналов.
- Локальное хранение, резервные копии, диагностика и управляемый перенос установки.
- Новые команды `edizora`, `edizora-web`, `edizora-local`, `edizora-ai-worker`, `edizora-desktop`.
- Новые переменные окружения `EDIZORA_*`; прежние `PUBLISHER_*` продолжают работать.
- Существующие данные прежнего приложения обнаруживаются без переноса работающих БД.

Скачайте `edizora.exe` со [страницы релиза](https://github.com/TheHolo/edizora/releases/tag/v0.1) и запустите установку. Python и Node.js устанавливать не требуется. Для публикаций по расписанию компьютер должен оставаться включённым.

Установщик пока не подписан цифровым сертификатом. Автоматическое обновление и независимая проверка на чистой машине Windows в этот выпуск не входят.
